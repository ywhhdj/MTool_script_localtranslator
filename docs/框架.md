#  硬性约束
- **不下载依赖、不执行构建/测试**：只产出工程源码与构建脚本，构建动作由使用者在本地执行。
- **可维护优先**：单一职责、接口隔离、模块边界清晰，禁止跨层反向依赖。
- **组件化优先**：组件之间解耦，可独立测试、可复用。
- **模块化优先**：模块之间解耦，模块之间依赖关系清晰，模块之间数据传递 minimal。
- **工作前必须先列清单规划**

# 分层架构
```
┌──────────────────────────────────────────────────────────────┐
│ 表现层  ui/          Vue 组件 + composables                    │
│  只从 core/index.ts（Facade）取数据，不直接 import 内核模块     │
├──────────────────────────────────────────────────────────────┤
│ 装配层  core/container.ts  组合根：唯一允许跨模块 new 的地方     │
├──────────────────────────────────────────────────────────────┤
│ Hook 层  core/hooks/       渲染引擎 / XHR / Fetch / WebSocket  │
│  依赖注入回调，不认识 Translator 具体类                        │
├──────────────────────────────────────────────────────────────┤
│ 引擎层  core/engine/       Translator（编排）+ Pipeline（热路径）│
│          core/rules/       规则库 / AI 修正 / 规则压缩          │
│          core/text/        归一化 / 过滤判定                    │
│          core/datastruct/  Bloom / LRU / 正则分块索引           │
│          core/io/          文件解析 / 导出 / 下载               │
├──────────────────────────────────────────────────────────────┤
│ 基础设施  core/infrastructure/  日志 / 存储 / 定时器 / 指标      │
│           core/platform/        宿主环境（window / rawFetch）   │
│           core/config/          配置中心（schema 驱动）         │
├──────────────────────────────────────────────────────────────┤
│ 领域层  core/domain/       纯类型 + 端口接口（零依赖）          │
└──────────────────────────────────────────────────────────────┘
```

依赖方向**自上而下单向**：`ui → container → hooks → engine → rules/text/datastruct/io → infrastructure/platform → domain`。
任何下层都不 import 上层；跨层通信通过「端口接口 + 注入回调」完成。
